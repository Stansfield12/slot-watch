# Мониторинг окон на практику (автошкола Антарес)

Каждые ~30 минут заходит в ваш кабинет, проверяет ближайшие 14 дней
(категория «B-механіка 1 година») на трёх адресах и шлёт в Telegram новые окна.
Приоритет: вул. Сінна, 1, затем Байди Вишневецького, 34 и пр. Перемоги, 25/2.
Ничего не бронирует, только читает.

## Установка (всё через браузер, ПК не нужен)

### 1. Telegram-бот
1. В Telegram откройте @BotFather → `/newbot` → задайте имя → получите **токен**
   (строка вида `123456:ABC...`).
2. Откройте своего нового бота и нажмите **Start** (отправьте ему любое сообщение).
3. Узнайте свой chat id: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id":ЧИСЛО`. Это и есть **chat id**.

### 2. Репозиторий на GitHub
1. github.com → **New repository**. Для первого запуска выберите **Private**.
2. Создайте файлы (Add file → Create new file), вставляя содержимое:
   - `monitor.py`
   - `requirements.txt`
   - `state.json`
   - `.github/workflows/monitor.yml`
     (в поле имени файла введите путь целиком, слэши создадут папки)

### 3. Секреты
Settings → Secrets and variables → Actions → **New repository secret**. Создайте четыре:

| Имя | Значение |
|---|---|
| `SITE_EMAIL` | email от кабинета автошколы |
| `SITE_PASSWORD` | пароль от кабинета |
| `TG_TOKEN` | токен бота |
| `TG_CHAT_ID` | ваш chat id |

### 4. Проверка
Вкладка **Actions** → workflow `monitor` → **Run workflow**:
1. Поставьте галочку **test** → придёт тестовое сообщение в Telegram.
2. Затем запуск с галочкой **debug** → в логе будет, что нашлось на каждом адресе и
   какие запросы делает сайт; при ошибке в артефакте `debug` будут скриншоты.
   Пришлите мне этот лог (текст, без пароля), и я подгоню скрипт под реальную вёрстку.

### 5. Боевой режим
Расписание запускается само. Чтобы оно было бесплатным и без ограничений по минутам,
после успешной отладки сделайте репозиторий **Public**
(Settings → General → Danger Zone → Change visibility).
Пароли в Secrets при этом остаются скрытыми, а в логах скрипт не печатает личных данных
(в режиме debug печатает, поэтому debug запускайте только в приватном репозитории).

В приватном репозитории лимит 2000 минут в месяц, при запуске раз в 30 минут их не хватит.

## Нюансы
- GitHub может задерживать запуски на 5-30 минут.
- Если 60 дней нет коммитов, расписание отключается. Скрипт сам обновляет `state.json`
  раз в ~10 дней, чтобы коммиты были. Если уведомления вдруг прекратились, загляните
  в Actions и включите workflow заново.
- Глубину проверки меняет `DAYS_AHEAD` в `monitor.yml`.
- Если на сайте появится капча или двухфакторка, вход перестанет работать, придёт
  сообщение «Мониторинг окон сломался».
- Ошибки не дублируются чаще раза в 12 часов.
